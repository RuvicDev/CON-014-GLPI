1. ¿Qué es y para qué sirve?

GLPI es una plataforma ITSM open source para gestionar tickets, activos y soporte. El conector permite crear tickets, actualizarlos, consultarlos y agregar seguimientos.

ticket.create_ticketCrea un ticket.
ticket.update_ticketActualiza un ticket.
ticket.get_ticketConsulta ticket.
ticket.add_followupAgrega seguimiento.

2. Prerrequisitos

  • Instancia GLPI local, Docker o de prueba.
  • API REST habilitada.
  • App Token y User Token.

3. Configuración en GLPI

  1. Activa la API REST en Setup → General → API.
  2. Genera App Token.
  3. Genera User Token para el usuario de prueba.

4. Permisos requeridos

El usuario debe tener permisos para crear, consultar, actualizar tickets y agregar seguimientos.

5. Configuración en Ruvic

Completa URL base GLPI, App Token y User Token. Los tokens se guardan como secretos.

6. Verificación

Ejecuta Probar conexión y crea un ticket de prueba.

7. Solución de problemas

401/403Tokens, API deshabilitada o permisos inválidos.
404Ticket o endpoint no encontrado.
Session tokenFallo iniciando sesión; revisa App Token y User Token.

8. FAQ y seguridad

No compartas tokens. Usa una instancia GLPI local o de prueba para validar. No se elimina tickets con este conector.
